# Class Git Rules

1. **Commit daily.** Labs always end in a commit. Fewer than 5 commits a week triggers a mentor follow-up.
2. **Write descriptive commit messages.** Good: `Add input validation to temperature converter`. Bad: `update`, `first commit`.
3. **Never commit secrets.** Passwords, connection strings and API keys go in `.env` (git-ignored). Hardcoded secrets in the capstone cost 10 points.
4. **Use one folder per week** in your cohort repo: `weeks/week-NN/{lab,practice,pair-programming,project}`.
5. **Use feature branches and PRs** for projects from Week 8 on; required for the TDD sprint (Week 11) and peer review (Week 13).
6. **Report course problems** with an Issue using the provided templates.
