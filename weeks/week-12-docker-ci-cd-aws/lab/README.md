# Week 12 Guided Lab: Deploy the Full-Stack App to AWS

**Time:** 11:00 AM – 12:00 PM · The instructor live-codes on the projector and students follow along.

## Steps
1. Dockerize the backend and run it locally.
2. Write `docker-compose.yml` for the backend + PostgreSQL.
3. Write a GitHub Actions workflow: tests on push to main, then build the image (the deploy step is configured).
4. Deploy the backend to EC2 with the provided SSH key and script.
5. Point the frontend at the AWS URL and verify the live app.

## Rules
- Wait for the whole class at each step.
- If more than half the class is stuck, pause and work through it together.
- If time runs out, simplify the lab; the full version becomes independent practice.
- The lab must end in a **GitHub commit**.
