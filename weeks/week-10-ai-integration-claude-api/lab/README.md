# Week 10 Guided Lab: Add an AI Feature to the Task Manager

**Time:** 11:00 AM – 12:00 PM · The instructor live-codes on the projector and students follow along.

## Steps
1. Store the Claude API key in an environment variable, never in code.
2. Create POST /tasks/suggest: send the task description to Claude and return 3 subtask suggestions as JSON.
3. Add a 'Get AI Suggestions' button in React that calls the backend and shows the results.
4. Validate the output: an empty or failed response shows a helpful message, never a blank screen.

## Rules
- Wait for the whole class at each step.
- If more than half the class is stuck, pause and work through it together.
- If time runs out, simplify the lab; the full version becomes independent practice.
- The lab must end in a **GitHub commit**.
