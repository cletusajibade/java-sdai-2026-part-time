## Learning objectives
- How LLMs work conceptually
- Claude Messages API: system prompts, messages, parameters
- Prompt engineering: system prompts, few-shot, chain-of-thought
- Where AI fits in the backend
- Streaming vs. non-streaming, error handling, rate limits
- Hallucination, PII, output validation
- Advanced Copilot: multi-file context, security review
- When NOT to use AI
- Cost: tokens, caching
