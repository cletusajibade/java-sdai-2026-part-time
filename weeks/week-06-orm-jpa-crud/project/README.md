# Week 6 Weekly Project: Full CRUD Application

A CLI app with full CRUD on a domain of your choice (recipes, movies, expenses, workouts). Use the ORM (no raw SQL strings in app code), handle exceptions, include at least one JOIN, and write a README with setup instructions.

## Submission checklist
- [ ] Code runs without errors
- [ ] README explains what it does and how to run it
- [ ] Descriptive commit messages
- [ ] No secrets committed (use `.env` / environment variables)
- [ ] Pushed to `weeks/week-06/project/` in your cohort repo
