# Week 6 Guided Lab: Connect the Library Database to Code

**Time:** 11:00 AM – 12:00 PM · The instructor live-codes on the projector and students follow along.

## Steps
1. Add Spring Data JPA to the project (configuration provided).
2. Create `@Entity` classes `Book`, `Member` and `Loan`.
3. Implement `findAllBooks()` returning `List<Book>`.
4. Implement `addBook(Book book)`.
5. Implement `deleteBook(int bookId)` with error handling, then verify the results in DBeaver.

## Rules
- Wait for the whole class at each step.
- If more than half the class is stuck, pause and work through it together.
- If time runs out, simplify the lab; the full version becomes independent practice.
- The lab must end in a **GitHub commit**.
