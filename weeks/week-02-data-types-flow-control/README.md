## Learning objectives
- Primitive types and String, and when to use each
- Type conversion: implicit vs. explicit casting and pitfalls
- Statements vs. expressions
- Arithmetic operators, modulo, integer division
- Comparison operators, and why `==` differs on objects
- Boolean logic (&&, ||, !) and truth tables
- if / else if / else
- for, while, do-while: when to use each
- Loop patterns: accumulator, counter, break and continue

## ☕ Java track notes
`int`, `double`, `boolean`, `char`, `String`. Use `Scanner` for input and `Math.random()` for random numbers.
