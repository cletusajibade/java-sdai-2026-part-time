# Week 11 Guided Lab: Test the Task Manager

**Time:** 11:00 AM – 12:00 PM · The instructor live-codes on the projector and students follow along.

## Steps
1. Write 3 unit tests for task creation: valid, no title, past due date.
2. Mock the repository with Mockito and test the service in isolation.
3. Write an integration test for POST /tasks: verify the status code and the saved record.
4. Run the suite and generate a coverage report (JaCoCo).

## Rules
- Wait for the whole class at each step.
- If more than half the class is stuck, pause and work through it together.
- If time runs out, simplify the lab; the full version becomes independent practice.
- The lab must end in a **GitHub commit**.
