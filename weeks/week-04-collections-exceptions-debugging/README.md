## Learning objectives
- Collections overview: ordered vs. unordered
- Arrays: indexing, iteration, off-by-one, null access
- Lists: add, remove, get, size, contains, indexOf
- Maps: key-value pairs and when to prefer them
- Iterating with for and enhanced for
- Exceptions: checked vs. unchecked
- try/catch/finally: handling vs. swallowing
- Custom exceptions
- IntelliJ debugger: breakpoints, stepping, inspecting
- Reading stack traces: NullPointerException, IndexOutOfBoundsException, NumberFormatException

## ☕ Java track notes
`ArrayList`, `HashMap`, `LinkedList`. Checked exceptions must be declared with `throws`. Use try-with-resources.
