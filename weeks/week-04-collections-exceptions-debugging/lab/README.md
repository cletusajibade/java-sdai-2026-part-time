# Week 4 Guided Lab: Student Grade Tracker with Exception Handling

**Time:** 11:00 AM – 12:00 PM · The instructor live-codes on the projector and students follow along.

## Steps
1. Create a `List<String>` of student names.
2. Create a `Map<String, List<Integer>>` from student to grades.
3. Write `addGrade(String student, int grade)`: throw a custom `InvalidGradeException` outside 0–100, otherwise add the grade.
4. Write `getAverage(String student)` and handle unknown students.
5. Wrap calls in try/catch with meaningful messages, then step through `addGrade` in the debugger.

## Rules
- Wait for the whole class at each step.
- If more than half the class is stuck, pause and work through it together.
- If time runs out, simplify the lab; the full version becomes independent practice.
- The lab must end in a **GitHub commit**.
