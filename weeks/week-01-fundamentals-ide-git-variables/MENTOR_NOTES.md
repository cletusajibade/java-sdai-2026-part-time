# Week 1 Mentor & Instructor Notes

> Instructor copy. Move this file to the private instructor repo if students can see the course repo.

- Setup week. Get every IDE running before students leave; watch for JDK version mismatches and the Copilot extension not activating.
- Git confusion (wrong branch, detached HEAD): don't fix it for them. Walk through `git status` so they learn to read Git output.
- Cert prep (2–3 PM): GitHub Foundations overview; students take the GitHub Skills diagnostic.
