## Learning objectives
- IDE setup: IntelliJ IDEA Community + VS Code, JDK 21, Maven
- GitHub account, first repository, the daily-commit habit
- Git workflow: init, add, commit, push, pull, clone, status
- GitHub Copilot: install the extension, first prompt
- Variables: declaration and naming
- Scope: local vs. class-level
- Naming conventions: camelCase, PascalCase, SCREAMING_SNAKE_CASE
- SDLC overview: the 14-week roadmap

## ☕ Java track notes
Use IntelliJ IDEA. Create a Maven project with a `Main` class containing `public static void main(String[] args)`.
