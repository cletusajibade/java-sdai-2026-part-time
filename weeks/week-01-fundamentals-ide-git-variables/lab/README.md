# Week 1 Guided Lab: First Program + First GitHub Commit

**Time:** 11:00 AM – 12:00 PM · The instructor live-codes on the projector and students follow along.

## Steps
1. Create a new Maven project in IntelliJ and run Hello, World! with your own name.
2. Store your name in a variable and print: `My name is [name] and I am learning Java.`
3. Create a GitHub repo named `claim-academy-[name]-cohort` and commit the program.
4. Exit criteria: working IDE, running program, at least one commit on GitHub.

## Rules
- Wait for the whole class at each step.
- If more than half the class is stuck, pause and work through it together.
- If time runs out, simplify the lab; the full version becomes independent practice.
- The lab must end in a **GitHub commit**.
