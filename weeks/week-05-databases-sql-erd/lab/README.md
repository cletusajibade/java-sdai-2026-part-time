# Week 5 Guided Lab: Design and Query a Library Database

**Time:** 11:00 AM – 12:00 PM · The instructor live-codes on the projector and students follow along.

## Steps
1. Design an ERD: Books (book_id, title, author, year), Members (member_id, name, email), Loans (loan_id, book_id, member_id, loan_date, return_date).
2. Create the tables in PostgreSQL (CREATE TABLE syntax provided).
3. Insert 5+ books, 3 members and 4 loans.
4. Query: books by an author; current loans (no return date); the top borrower (COUNT + GROUP BY); a JOIN of books with borrower names; UPDATE a return date.

## Rules
- Wait for the whole class at each step.
- If more than half the class is stuck, pause and work through it together.
- If time runs out, simplify the lab; the full version becomes independent practice.
- The lab must end in a **GitHub commit**.
