## Learning objectives
- Why applications need a database
- Tables, rows, columns, primary keys, foreign keys
- Normalization basics (1NF, 2NF)
- Reading and designing ERDs
- SELECT, FROM, WHERE, ORDER BY, LIMIT
- AND, OR, NOT, LIKE, IN, BETWEEN
- COUNT, SUM, AVG, MIN, MAX, GROUP BY, HAVING
- INNER JOIN and LEFT JOIN
- INSERT, UPDATE, DELETE (always with WHERE)
- Local PostgreSQL setup

## ☕ Java track notes
