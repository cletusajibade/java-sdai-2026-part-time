# Week 3 Guided Lab: Animal Hierarchy

**Time:** 11:00 AM – 12:00 PM · The instructor live-codes on the projector and students follow along.

## Steps
1. Create `Animal` with `name`, `sound`, a constructor, and `speak()` printing `[name] says [sound].`
2. Create `Dog extends Animal` and add `fetch()`.
3. Create `Cat extends Animal` and override `speak()` to print `[name] says [sound] softly.`
4. In `main`, create an Animal, a Dog and a Cat, and call `speak()` on each to observe polymorphism.
5. Add a `Trainable` interface with `train()`; have `Dog` implement it.

## Rules
- Wait for the whole class at each step.
- If more than half the class is stuck, pause and work through it together.
- If time runs out, simplify the lab; the full version becomes independent practice.
- The lab must end in a **GitHub commit**.
