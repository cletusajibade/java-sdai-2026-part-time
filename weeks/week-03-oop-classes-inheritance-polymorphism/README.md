## Learning objectives
- Why OOP exists: the real-world object analogy
- Classes vs. instances (blueprint vs. house)
- Fields, methods and constructors (default and parameterized)
- Encapsulation: private fields, getters and setters
- Polymorphism: overriding vs. overloading
- Inheritance: what is and isn't inherited
- Abstract classes vs. interfaces
- Static vs. instance members

## ☕ Java track notes
`public class`, `extends`, `implements`, `@Override`, `abstract`, `interface`. Demonstrate method overriding with concrete examples.
