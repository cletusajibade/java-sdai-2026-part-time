# Week 7 Guided Lab: Build a Developer Portfolio Page

**Time:** 11:00 AM – 12:00 PM · The instructor live-codes on the projector and students follow along.

## Steps
1. Build `index.html` with header, nav, main, section and footer.
2. Style it with Flexbox and make it responsive.
3. Add a Projects section with 3 cards (title, description, GitHub link).
4. Add one interactive element (a dark-mode toggle or an add-project form).
5. Convert the project cards into a React component that takes props, then deploy to GitHub Pages.

## Rules
- Wait for the whole class at each step.
- If more than half the class is stuck, pause and work through it together.
- If time runs out, simplify the lab; the full version becomes independent practice.
- The lab must end in a **GitHub commit**.
