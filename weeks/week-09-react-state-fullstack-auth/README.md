## Learning objectives
- Hooks: useState, useEffect, useContext, useRef, useMemo
- React Router v6: nested and protected routes
- State management with the Context API
- Calling APIs: Axios/fetch, loading and error states, async/await
- Controlled forms and validation
- CORS and environment-based API URLs
- Production build preview

## ☕ Java track notes
React calls the Spring Boot API with Axios and an `Authorization: Bearer` header. Configure CORS in Spring Security.
