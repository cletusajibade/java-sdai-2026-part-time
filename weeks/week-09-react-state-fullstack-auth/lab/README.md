# Week 9 Guided Lab: Full-Stack Task Manager Application

**Time:** 11:00 AM – 12:00 PM · The instructor live-codes on the projector and students follow along.

## Steps
1. Display the task list from the Week 8 API in React.
2. Add a create-task form that POSTs and then refreshes the list.
3. Add a Mark Complete button that calls PATCH.
4. Add a Delete button with confirmation.
5. Add JWT login: a form calls /auth/login, keeps the token in memory, and sends it with later requests.

## Rules
- Wait for the whole class at each step.
- If more than half the class is stuck, pause and work through it together.
- If time runs out, simplify the lab; the full version becomes independent practice.
- The lab must end in a **GitHub commit**.
