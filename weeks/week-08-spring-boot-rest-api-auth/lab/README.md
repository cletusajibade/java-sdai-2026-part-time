# Week 8 Guided Lab: Task Manager REST API

**Time:** 11:00 AM – 12:00 PM · The instructor live-codes on the projector and students follow along.

## Steps
1. Generate a Spring Boot project (see the note below).
2. Create a `Task` entity (id, title, description, isComplete, dueDate).
3. Implement GET /tasks, GET /tasks/{id}, POST /tasks, PUT /tasks/{id} and DELETE /tasks/{id}.
4. Persist tasks with the Week 6 database setup.
5. Document the endpoints with OpenAPI/Swagger.
6. Test in Postman or the Swagger UI, not the browser URL bar.

## Rules
- Wait for the whole class at each step.
- If more than half the class is stuck, pause and work through it together.
- If time runs out, simplify the lab; the full version becomes independent practice.
- The lab must end in a **GitHub commit**.
