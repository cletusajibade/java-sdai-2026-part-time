# Week 14 Guided Lab: Demo Day Dry Run

**Time:** 11:00 AM – 12:00 PM · The instructor live-codes on the projector and students follow along.

## Steps
1. Mon–Tue: final polish and a 15-minute architecture review with each student.
2. Wed: full 10-minute dry run for the cohort; peers give one clear point, one confusing point, and one likely employer question.
3. Thu: revisions, verify the live URL, and test the AI feature with 5 different inputs.
4. Fri: DEMO DAY.

## Rules
- Wait for the whole class at each step.
- If more than half the class is stuck, pause and work through it together.
- If time runs out, simplify the lab; the full version becomes independent practice.
- The lab must end in a **GitHub commit**.
