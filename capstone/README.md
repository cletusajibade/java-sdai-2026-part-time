# Capstone: AI-Enabled Full-Stack Application (Java Track)

## Timeline
| Week | Milestone |
|---|---|
| 7 | 1-paragraph capstone idea submitted for approval |
| 12 | 1-page architecture document approved ([template](templates/architecture-doc.md)) |
| 13 | **Milestone 1:** all endpoints working, schema migrated, 1+ Claude feature; 5-minute progress presentation |
| 14 | Final deliverable + **Demo Day** (10-minute presentation + 5-minute Q&A) |

## Final requirements
- [ ] Live deployment with a public URL (AWS)
- [ ] Database-backed, with a proper schema and sample data
- [ ] 2+ meaningful Claude API features (backend only, validated output) + [AI Design Doc](templates/ai-design-doc.md)
- [ ] JWT authentication (login/logout)
- [ ] Unit + integration + at least 1 mock test; 60%+ service-layer coverage
- [ ] GitHub Actions CI/CD (deploys only when tests pass)
- [ ] README: description, tech stack, architecture diagram, screenshots, live link, setup instructions

## Rubric (100 points, 70 to pass)
| Component | Pts | Full marks |
|---|---|---|
| Functionality & features | 25 | Works end to end; AI adds real value |
| Code architecture & quality | 20 | OOP/SOLID, patterns, readable. **Hardcoded secrets: −10** |
| AI integration | 20 | 2+ Claude features; documented prompts; edge cases; validated output |
| Cloud deployment & DevOps | 15 | Live URL; CI/CD passing; stable for 5 minutes of employer use |
| Testing | 10 | Unit + integration + mock; 60%+ coverage |
| Presentation & Q&A | 10 | Clear story; 3+ questions answered |

The written/technical portion can be resubmitted within 5 business days; the Demo Day score is final.
